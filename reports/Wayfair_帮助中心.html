1. 使用流程

日常工作从哪里开始？

从「执行中心」开始，按 执行中心 → 库存映射 → 促销准入 → 广告/关键词清单 的顺序走。Dashboard 首页只做导航，不承载工作内容。

什么时候看「分析与档案」？

对单个 SKU 的动作有疑问时，去 SKU 经营档案、SKU 价值分级、定价体检表、评分评论体检回查证据，再决定执行或调整。

动手前要检查什么？

广告、促销、Listing 改动前先过一遍「操作护栏」和「Cost Stack 口径校准」，避免口径错误和误操作。

店铺复盘按什么顺序做？

按培训课模型：业绩 = 流量 × 转化 × 客单价。先看账号整体，再看类目，再看 SKU / Parts；最后只落最多 3 个动作，分别对应止损、修承接、放量验证。

2. 页面说明

📌 今日工作

执行中心：本周必须先处理的 SKU、原因和动作（工作第一入口）；SKU 任务清单：按 P0/P1/P2 聚合的全量 178 条任务；待办甘特图：任务节奏和时间安排。

🎯 执行清单

SKU 分层与促销准入：判断哪些能促销、哪些先停；WSP 广告调整：Campaign/Product 层动作；WSP 关键词调整：保留、降 bid、暂停建议。

🔍 分析与档案

SKU 经营档案：单 SKU 成本、库存、广告、促销和 Listing 证据；SKU 价值分级：S/A/B/C/N 分层；产品定价体检表：成本、订单、扣款和 Base 建议；Product Catalog 定价体检：供货价、前台价和成本空间；评分评论体检：评分、评论、图片、CVR。

📦 数据与工具

库存映射对照：686 行库存，仓库 SKU 对 Wayfair SKU；数据补齐清单：已收数据和仍缺数据；项目状态简报：项目状态、数据补齐进度和风险汇报。

🛡️ 规则与背景

操作护栏：广告、促销、Listing 防错规则；Cost Stack 校准：成本口径护栏；店铺诊断：问题、机会和结论；店铺交接：接手原则和流程。

3. 操作指南

如何标记任务"已执行"？

在「执行中心」或「任务清单」里，点击任务行的状态按钮（带 ▾ 角标的圆角标签），按 待执行 → 执行中 → 已执行 → 暂缓 循环切换。标记"已执行"时自动记录当天日期。

执行中心和任务清单的进度同步吗？

同步。两个页面共用同一份进度记录，在任意一边标记，另一边刷新后状态一致。执行中心顶部显示"本周已执行 X / 20"，任务清单显示全量进度条。

标记的进度保存在哪里？

保存在当前浏览器的 localStorage 里：刷新、关闭页面都不丢失；但换浏览器或换电脑不会同步，清除浏览器数据会清空进度。注意：进度只在正式域名 ai-wayfair.vercel.app 记录，预览链接是独立环境看不到你的进度；任务清单顶部有"重置全部进度"按钮可一键清空。

如何筛选任务？

任务清单顶部有筛选按钮：全部 / P0 / P1 / P2 / 待执行 / 已执行 / 暂缓，点击即可过滤表格行。

表格太宽看不全？

数据表支持横向滚动，首列（SKU）保持固定方便对照；部分长文本默认折行截断，点击"成本明细"等折叠项可展开。

4. 数据口径与护栏

Cost Stack 用哪个口径？

平台空间看 Retail Price Net − Total Cost。当前有效版本是 5 月；6 月导出只有表头、0 条数据，价格结论暂不使用它，等有效报表出来后替换并重跑分级/准入。

周复盘只看哪些数据？

每周复盘强制更新订单数据和 WSP 五类广告报表：Campaign、Product、Keyword Targeting (Listing)、Keyword Optimization、Search Term Research。Campaign/Product 用来判断停、降、保留和加预算；Keyword/Search Term 用来判断停词、降 bid、扩词和搜索词机会。Report Center 的 Listing Health、Option Drill Down、Cost Stack、Customer Feedback 等按月或有效导出时纳入。

哪些 SKU 可以进入放量验证？

必须同时满足有订单或明确需求、有正毛利、库存健康、CVR 不弱于类目、Listing Green 或可快速修复、广告 ROAS 可解释。任一项是库存不足、评分低、客诉未闭环或广告 0 单高消耗，就先止损或修承接。

为什么"库存先行"？

加预算、进促销、补货前必须先查库存映射；映射置信度为中/低或未匹配的条目，人工复核之前不要用于任何决策。

为什么不能用单一报表做决策？

广告、促销动作必须合并 SKU 价值、库存、评分、客诉多维度判断，单看一张表容易误停、误促。

WSS 报表 0 行怎么处理？

按未投放/无数据处理，不进入任何分析结论。

5. 其他

归档页面在哪里？

已废弃的旧页面（如旧版项目导航、过期定价体检占位页）已下线归档（保存在代码仓库 reports/archive/，不发布到线上），需要时联系维护者取回。

报告文件名里的日期是什么意思？

表示该报告的生成/更新版本（如 20260605）。同名报告以日期最新的为准，导航始终链接最新版。
