06 / LEARNING SYSTEM

记录、学习与SOP升级

每次动作必须留下“假设、改动、结果、结论、下一步”。没有记录的经验不能进入SOP，没有复测的结论不能成为规则。

LEARNING RULE L01

L1 数据先行

数据完整率≥95%，来源、窗口、口径和更新时间齐全

不满足只标记“待验证”，不得形成规则
LEARNING RULE L02

L2 单变量

一个Operation只改变一个关键变量

多变量同时变化时只能记录相关性，不能归因
LEARNING RULE L03

L3 观察窗

广告至少7天或20点击；Offer至少14天；活动周期采用同口径日均

未成熟不得提前判定输赢
LEARNING RULE L04

L4 证据链

前快照→审批→执行→后结果→验收→成熟复盘

任一缺失则状态不得进入“已验证”
LEARNING RULE L05

L5 升级门槛

连续2个观察周期方向一致，或1个完整月证据充分且人工批准

才可从“候选规则”升级为“SOP规则”
LEARNING RULE L06

L6 回退机制

任何规则必须写触发条件、停止条件、回退动作和适用范围

护栏被突破时自动降级为待复核
LEARNING RULE L07

L7 版本管理

规则ID + 版本 + 生效日 + 证据Operation ID + 批准人

旧版本保留，不覆盖历史

月度闭环：把8月执行结果升级成下一月的默认做法
