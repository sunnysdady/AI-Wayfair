# AI-Wayfair

Wayfair 店铺运营接手与诊断项目。

线上入口： https://ai-wayfair.vercel.app

## 目录结构

- `index.html`：Vercel 首页，同事优先从这里进入。
- `reports/`：可公开给同事查看的 HTML 报告与导航页。
- `docs/`：内部接力文档、知识库、MEMORY、操作口径等 Markdown 文档。
- `data/`：结构化数据导出，例如 SKU 分级 CSV。
- `archive/`：本地备份文件，不作为主要工作入口。
