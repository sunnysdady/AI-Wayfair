## 2. 本轮（2026-06-05 ~ 06-06）已完成的工作

### 2.1 报告排版全面修复（commit abc9c92）

问题：所有带表格的页面排版混乱——"执行状态"按钮文字竖排、"触发原因/建议动作"列撑爆行高、列宽完全失控。

根本原因（3 层）：
1. `dashboard-shell.js` 的 JS 给所有 `<table>` 注入 `min-width: columns×130px`，使列宽平均分配
2. 没有 `<colgroup>` 约束，浏览器按内容自动分配列宽
3. 长文字列没有截断（`-webkit-line-clamp`）

修复方案：
- 在 `body` 内嵌 `_TABLE_STYLES`（含 `table-layout:fixed`、colgroup 宽度定义、`.lc2/.lc3/.lc4` 截断类）
- `task_table()` → `class='exec-tbl'`，7 列 colgroup，触发原因 lc4、建议动作 lc3、复盘指标 lc3
- `interactive_task_table()` → `class='task-tbl'`，8 列 colgroup
- `render_execution_center()` body 头部插入 `_TABLE_STYLES`
- `dashboard-shell.js` 的 min-width 注入排除 `task-tbl`/`exec-tbl`

修改文件：
- `scripts/build_ops_workbench.py` — 表格生成逻辑

## 5. 重要技术约束（下一轮必须知道）

### Shell 覆盖 `<head>`
`apply_dashboard_shell.py` 会完全替换 `<head>`。任何页面专有的 CSS/JS 必须放在 `<body>` 内，否则被覆盖后失效。已有案例：
- 甘特图 CSS → 直接 `<style>` 写在 `<main id="content">` 前
- 任务表/执行中心表 CSS → `_TABLE_STYLES` 常量写在 body 头部

### Shell JS min-width 注入
`dashboard-shell.js` 会对所有 `<table>` 注入 `min-width: columns×130px`。已通过 `classList.contains` 检查排除 `task-tbl` 和 `exec-tbl`。如新增其他固定布局表格，需要同样加到排除列表。

### 本地预览服务器
```bash
python3 -m http.server 8787 --directory reports
# 然后访问 http://localhost:8787/
```

### 重新生成报告流程
```bash
cd /Users/pengzhang/Documents/Helloclaude/AI-Wayfair
```
