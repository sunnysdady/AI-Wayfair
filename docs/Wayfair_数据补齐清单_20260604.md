# Wayfair 数据补齐清单

更新时间：2026-06-04

## 1. 最高优先级

| 数据 | 日期范围 | 用途 | 文件命名建议 |
|---|---|---|---|
| WSP Keyword Optimization Report | 06/01/2026 至当前 | 关键词停词、降 bid、保留词 | `WSP_Keyword_Optimization_20260601_当前日期` |
| WSP Keyword Targeting Report (Listing) | 06/01/2026 至当前 | Listing x Keyword 诊断 | `WSP_Keyword_Targeting_Listing_20260601_当前日期` |
| 最新 Cost Stack Report | 最新可导出周期 | 平台空间、物流/退货/补贴成本 | `Cost_Stack_最新日期` |
| 当前库存表 | 当前时点 | 防止缺货 SKU 加预算/进促销 | `Inventory_当前日期` |

## 2. 第二优先级

| 数据 | 用途 |
|---|---|
| Detailed Listing Health | 修 TAG、必填属性、推荐属性 |
| Option Drill Down | 颜色/尺寸/选项维度转化 |
| Customer Feedback Report | 客诉与差评原因 |
| Cancellations Overview | 取消率和履约风险 |
| Promotions Performance | 促销效果复盘 |
| 当前促销/折扣清单 | 做促销准入和禁促 |
| Review 数量和星级 | 判断转化承接 |
