# Wayfair 操作护栏

更新时间：2026-06-04

## 1. Cost Stack 护栏

正确平台空间：

`Retail Price Net - Total Cost`

禁止：

- 禁止用 `WholesaleCost - Total Cost` 判断平台亏损。
- 禁止只因为 `WholesaleCost < Total Cost` 就停投、禁促或判定负毛利。

每次使用 Cost Stack 必须写清：

1. 数据源日期。
2. `Retail Price Net`。
3. `Total Cost`。
4. 平台空间。
5. 物流、退货、Product Allowance、Other Handling 是否异常。
6. 卖家真实利润是否已核准。

## 2. 广告护栏

- 不能只看 ROAS。
- 不能用 5 月 Keyword 报告做 6 月停词最终依据。
- 6 月 WSP Product/Campaign 可以先做产品层暂停/降预算。
- Keyword 层必须重新导出 6 月报告后再停词。
- 有订单的 SKU 不直接加预算，先查库存、利润、客诉。

## 3. 促销护栏

进入促销前必须同时满足：

- 卖家真实毛利为正。
- 折扣后仍有利润。
- 平台空间不低。
- 库存充足。
- 客诉/退货风险可控。
- Listing 承接不差。

禁止：

- 订单毛利率低于 20% 的 SKU 进促销。
- 未核算 Cost Stack 和卖家利润的 SKU 进大促。
- 客诉/退货异常 SKU 进促销。

## 4. Listing 护栏

优先修：

- TAG 覆盖不足。
- 图片不足或 Browse Hero 不合格。
- Review 少于 20。
- CTR 高但 CVR 低的 SKU。
- 广告花费 0 单但点击不低的 SKU。

## 5. 输出护栏

每份报告必须包含：

- 数据源和日期范围。
- 口径说明。
- 动作清单。
- 暂停/降预算/保留/修 Listing/补数据的原因。
- 下一步。
