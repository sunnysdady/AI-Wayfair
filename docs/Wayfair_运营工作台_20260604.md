## 3. 现在优先做

| 动作 | 对象 | 说明 |
|---|---|---|
| 库存校验 | 广告/促销候选 SKU | 先用库存映射工具查高置信库存，再决定是否加预算/进促销 |
| 暂停/最低预算 | 6月 WSP Product 层有花费但 0 单的 Listing | 不等同于 SKU 淘汰，只是先停低效投放 |
| 保留小预算 | 已有归因订单、历史价值较高 SKU | 加预算前必须同时看库存、利润、客诉和评分 |
| 承接诊断 | 有点击但不转化的 Listing | 查 PDP、价格、评价、库存、真实利润 |
| 人工复核 | 库存映射中/低置信和未匹配项 | 未复核前不要用于补货、停投或促销决策 |
